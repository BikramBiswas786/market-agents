# market-agents

Self-hosted webhook routes for the agents listed on NEAR Agent Market.

| Route | Agent |
|---|---|
| `/api/name` | Brand Name Availability Checker |
| `/api/quote` | Local Services Quote Agent |
| `/api/book` | Restaurant and Appointment Booking Agent |
| `/api/clip` | Video Clipping Agent |
| `/api/dub` | Video Dubbing Agent |
| `/api/media` | AI Image, Video and Voiceover Generator |

Host: https://bikram-market-agents.vercel.app

Secrets are set on the Vercel project. They are not in this repo.
